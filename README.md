# 语音输入交互探索 (React)

按图示还原的「输入框 + 语音输入」交互 Demo，用于探索可行性。

## 四个状态

| 状态 | 触发 | 退出 | 说明 |
|------|------|------|------|
| **默认空态** | 无文字 | — | `+` / 模型选择 / **合并后的麦克风**（空态时简化&合并按钮） |
| **直接输入**（分支一） | 键入文字 | 发送 / 清空 | 出现深色发送按钮 `↑` |
| **点击进入语音**（分支二） | 点击 🎙 麦克风 | **仅点击停止按钮** | 左侧有 **撤回** 按钮：撤回本次插入的文字并退出；停止按钮保留文本并退出 |
| **按住快捷键语音**（分支三） | 按住 `Ctrl` / `⌘` 约 **0.4s**（防抖判定延迟） | **松开即退出（无延迟）** | 更轻更快：**无撤回**，仅「松开退出」提示 + 停止按钮 |

### 关键差异（与你的要求一致）
- 点击按钮进入的语音输入 → **只能点击按钮退出**，且支持「撤回文本插入」。
- 按住快捷键进入的语音输入 → **松开按键即退出**，**无撤回**模式，更轻更快。
- 快捷键需按住 0.4s 才判定进入，避免误触（防抖）。
- 识别文字**基于光标所在位置实时插入**（可先把光标点到已有文字中间再试）。

## 本地运行

```bash
npm install
npm run dev
```

## 构建 / 部署

```bash
npm run build      # 产物在 dist/，base 已设为 './'，可托管到任意静态目录
npm run preview
```

可直接部署到 Vercel / Netlify / GitHub Pages 等（framework 选 Vite）。

> 说明：麦克风为交互原型，语音识别为**模拟**吐字，不调用真实 ASR。
